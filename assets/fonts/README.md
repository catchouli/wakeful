# Fonts

- `PixelOperator8.ttf` — Pixel Operator 8 Regular by Jayvee Enaguas
  (HarvettFox96), dedicated to the public domain via
  [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
  Source: <https://fontlibrary.org/en/font/pixel-operator>.

The font's em is exactly its 8px design block, so rendering at 8px
puts each glyph pixel on the game's virtual pixel grid. See
`src/text.rs` for how the game loads and applies it.
